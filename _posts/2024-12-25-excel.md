### Key Functions

#### **INDEX** Functionality
  - Syntax: **INDEX(table, row_number, column_number)**
   - **table**: A range of cells that contains the table of data
   - **row_number**: The row position in the table where the value you want to lookup is located
   - **column_number**: The column position in the table where the value you want to lookup is located

#### **VLOOKUP** Functionality
  - Syntax: **VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])**
    - **lookup_value**: Select the value to look up
    - **table_array**: A range of cells that contains the table of data
    - **col_index_num**: The number of the column you are looking up to
    - **[range_lookup]**:
      - Type **TRUE** to find <em> approximate </em> match
      - Type **FALSE** to find <em> exact </em> match

#### **SUM** Functionality
  - Select a cell
  - Type = SUM(
  - Enter the range of cells to add (ex. = SUM(A2:A10))
  - Press enter
  - RESULT: Adds all values from cell A2 to A10
