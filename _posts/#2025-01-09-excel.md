### Key Functions

#### **INDEX** Functionality
  - Syntax: **INDEX(table, row_number, column_number)**
   - **table**: A range of cells that contains the table of data
   - **row_number**: The row position in the table where the value you want to lookup is located
   - **column_number**: The column position in the table where the value you want to lookup is located

#### **VLOOKUP** Functionality
  - Syntax: **VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])**
    - **lookup_value**: Select the value to look up
    - **table_array**: A range of cells that contains the table of data
    - **col_index_num**: The number of the column you are looking up to
    - **[range_lookup]**:
      - Type **TRUE** to find <em> approximate </em> match
      - Type **FALSE** to find <em> exact </em> match

#### **SUM** Functionality
  - Select a cell
  - Type = SUM(
  - Enter the range of cells to add (ex. = SUM(A2:A10))
  - Press enter
  - RESULT: Adds all values from cell A2 to A10

#### **SUMIFS** Functionality
  - Syntax: **SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)**
    - **sum_range**: The range of cells to sum.
    - **criteria_range1**: The range that is tested using Criteria1.
    - **criteria1**: The criteria that defines which cells in Criteria_range1 will be added.
    - Example: <img src="/assets/files/pictures/sumifs.png" width="90%" height="90%" style="border:none;">

#### **AVERAGE** Functionality
  - Syntax: **AVERAGE(number1, [number2], ...)**
    - **number1**: The first number, cell reference, or range for which you want the average.
    - **number2, ...**: Additional numbers, cell references or ranges for which you want the average, up to a maximum of 255. 

#### **AVERAGEIFS** Functionality
  - Syntax: **AVERAGEIFS(average_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)**
    - **average_range**:  One or more cells to average, including numbers or names, arrays, or references that contain numbers.
    - **criteria_range1**:  subsequent criteria_ranges are optional. 1 to 127 ranges in which to evaluate the associated criteria.
    - **criteria1**: 1 to 127 criteria in the form of a number, expression, cell reference, or text that define which cells will be averaged. 


#### **COUNTIFS** Functionality
  - Usage: COUNTIFS function applies criteria to cells across multiple ranges and **counts the number of times all criteria are met**.
  - Syntax: **COUNTIFS(criteria_range1, criteria1, [criteria_range2, criteria2]…)**
    - **criteria_range1**:  The first range in which to evaluate the associated criteria.
    - **criteria1**: The criteria in the form of a number, expression, cell reference, or text that define which cells will be counted.

#### **NOW** Functionality
  - Usage: Returns the current date and time.
  - Syntax: No arguments, just call the function like **=NOW()**
  - Examples of usage:
    - = NOW()
      - returns 1/6/2025 19:52
    - = NOW() - 0.5
      - returns date and time 12 hours ago
      - returns 1/6/2025/ 7:52
    - = NOW() + 7
      - returns date and time 7 days in the future
      - returns 1/13/2025 19:52
    - = NOW() - 2.25
      - returns date and time 2 days and 6 hours ago
      - returns 1/4/2025 13:52

#### **TODAY** Functionality
  - Usage: Returns the current date.
  - Syntax: No arguments, just call the function like **=TODAY()**
  - Examples of usage:
    - = TODAY()
      - returns 1/6/2025
    - = TODAY() + 5
      - returns the current date plus 5
      - returns 1/11/2025
    - = DAY(TODAY())
      - returns the current day of the month (1 ~ 31)
      - returns 11
    - = MONTH(TODAY())
      - returns the current month of the year (1 ~ 12)
      - returns 1

#### **YEAR** Functionality
  - Usage: Returns the year corresponding to a date. The year is returned as an integer in the range 1900-9999.
  - Syntax: **YEAR(serial_number)**
    - **serial_number**: The date of the year you want to find.

#### **PMT** Functionality
  - Usage: Calculates the payment for a loan based on constant payments and a constant interest rate. 
  - Syntax: **PMT(rate, nper, pv, [fv], [type])**
    - **rate**: The interest rate for the loan
    - **nper**: The total number of payments for the loan
    - **pv**: The present value, or the total amount that a series of future payments is worth now.
    - **fv**: <em>Optional</em>, The future value, or a cash balance you want to attain after the last payment is made.
    - **type**: <em>Optional</em>, The number 0 (zero) or 1 and indicates when payments are due.

#### **CUBE** Functionality
  - **CUBEKPIMEMBER function**:
    - Returns a key performance indicator (KPI) property and displays the KPI name in the cell.
